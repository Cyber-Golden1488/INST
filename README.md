# Instagram Downloader

Полностью автономная утилита командной строки на Python (схема Zero-Setup) для скачивания видео и Reels из Instagram по ссылке в максимальном качестве без потерь.

## Особенности
- **Zero-Setup (Всё включено)**: Утилита сама создает виртуальное окружение, скачивает нужные библиотеки (`yt-dlp`, `tqdm`) и портативную версию `FFmpeg` для вашей ОС при первом запуске. Никаких ручных установок не требуется.
- Скачивание видео в наивысшем доступном качестве без перекодирования потоков (через `yt-dlp`) и автоматическое слияние потоков с помощью локального `FFmpeg`.
- Интерактивный прогресс-бар скачивания с помощью `tqdm`.
- Обработка ошибок (битые ссылки, отсутствие сети, приватные видео) с понятными сообщениями на русском языке.
- Удобный CLI-интерфейс и интерактивный режим (поддержка `run.bat` для Windows).

## Требования

- Установленный **Python 3.7 или новее**. Больше ничего!

## Быстрый запуск (Windows)

Для пользователей Windows предусмотрен удобный скрипт `run.bat`:
1. Просто запустите `run.bat` двойным щелчком.
2. При первом запуске он автоматически настроит среду.
3. Введите ссылку на видео или Reels, когда программа об этом попросит.

Вы также можете использовать `run.bat` в командной строке, передавая аргументы:
```cmd
run.bat "https://www.instagram.com/p/XXXXXXXXXXX/" -o "C:\Downloads"
```

## Использование (Все ОС)

Для запуска утилиты напрямую через Python используйте команду:

```bash
python ig_downloader.py [ссылка_на_видео] [опции]
```

Если запустить скрипт без ссылки, он перейдет в интерактивный режим и попросит её ввести.

### Доступные опции:
- `-o`, `--output` : Путь к папке для сохранения видео. По умолчанию видео сохраняется в текущую папку.
- `-h`, `--help` : Показать справку по использованию.

### Примеры:

Скачать видео в текущую папку:
```bash
python ig_downloader.py "https://www.instagram.com/p/XXXXXXXXXXX/"
```

Скачать видео и сохранить его в указанную папку `/path/to/downloads`:
```bash
python ig_downloader.py "https://www.instagram.com/p/XXXXXXXXXXX/" -o /path/to/downloads
```

## Возможные ошибки

Программа умеет распознавать и выводить на русском языке следующие ошибки:
- Некорректная ссылка на видео (Unsupported URL).
- Проблемы с сетевым подключением.
- Приватное видео (требует авторизации).
- Видео не найдено или удалено.
