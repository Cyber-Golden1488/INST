# Instagram Downloader

Утилита командной строки на Python для скачивания видео и Reels из Instagram по ссылке в максимальном качестве без потерь.

## Особенности
- Скачивание видео в наивысшем доступном качестве без перекодирования потоков (через `yt-dlp`).
- Интерактивный прогресс-бар скачивания с помощью `tqdm`.
- Обработка ошибок (битые ссылки, отсутствие сети и приватные видео) с понятными сообщениями на русском языке.
- Удобный CLI-интерфейс (через `argparse`), поддерживающий указание папки для сохранения.

## Требования

- Установленный Python 3.7 или новее.
- Утилита `ffmpeg` (опционально, но настоятельно рекомендуется для объединения видео и аудио потоков наивысшего качества).

## Установка

1. Клонируйте репозиторий или скачайте файлы проекта.
2. Установите необходимые зависимости из `requirements.txt`:

```bash
pip install -r requirements.txt
```

## Использование

Для запуска утилиты используйте команду:

```bash
python ig_downloader.py <ссылка_на_видео> [опции]
```

### Доступные опции:
- `-o`, `--output` : Путь к папке для сохранения видео. По умолчанию видео сохраняется в текущую папку.
- `-h`, `--help` : Показать справку по использованию.

### Примеры:

Скачать видео в текущую папку:
```bash
python ig_downloader.py "https://www.instagram.com/p/XXXXXXXXXXX/"
```

Скачать видео и сохранить его в указанную папку `/path/to/downloads`:
```bash
python ig_downloader.py "https://www.instagram.com/p/XXXXXXXXXXX/" -o /path/to/downloads
```

## Возможные ошибки

Программа умеет распознавать и выводить на русском языке следующие ошибки:
- Некорректная ссылка на видео (Unsupported URL).
- Проблемы с сетевым подключением.
- Приватное видео (требует авторизации).
- Видео не найдено или удалено.
